# Interactive Quiz App

## Week 2 – Core Concepts and Skills

This project was created as part of Week 2 of my internship. It demonstrates practical application of core web development concepts through a simple interactive quiz application.

## Project Objectives

- Practice HTML page structure.
- Apply CSS styling and responsive layout concepts.
- Use JavaScript variables, arrays, objects, functions, conditions, loops, and event listeners.
- Practice DOM manipulation.
- Build a small project from individual concepts.
- Test and improve the application through practical use.
- Maintain the project using Git and GitHub.

## Features

- Multiple-choice questions
- Interactive answer buttons
- Correct and incorrect answer feedback
- Score calculation
- Progress indicator
- Restart quiz option
- Responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Project Structure

```text
week-2-interactive-quiz/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Answer the questions and complete the quiz.

## Learning Outcome

This project helped me understand how HTML, CSS, and JavaScript work together to create an interactive web application. It also provided practical experience with DOM manipulation, event handling, conditional logic, arrays, objects, functions, and basic project organization.
